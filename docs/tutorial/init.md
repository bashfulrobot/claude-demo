# 1. Scaffold

In your Claude Code session at the repo root:

```text
/kong-skill-init <skill-name>
```

Use a short, hyphenated name for the job, e.g. `call-followup-email`.

In one shot this creates the plugin folder, a draft `plugin.json` and `SKILL.md`, registers the skill in the marketplace catalog, and wires up dependencies. You'll see a new `plugins/<skill-name>/` folder.
