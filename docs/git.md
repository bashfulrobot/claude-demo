# git

Version control — and a dependency for almost everything else.

**Check** (skip if it prints a version):

```bash
git --version
```

**Install:**

=== "macOS"

    ```bash
    brew install git
    ```

=== "Ubuntu / Debian"

    ```bash
    sudo apt update
    sudo apt install git -y
    ```
