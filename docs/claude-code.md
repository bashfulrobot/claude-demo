# Claude Code

The agent you'll use to build skills.

**Check** (skip if it prints a version):

```bash
claude --version
```

**Install** (same command on macOS and Ubuntu):

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

!!! info "Auto-updates"
    The native install keeps itself up to date in the background.
