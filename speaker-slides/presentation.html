Principles

Deterministic by design

The model orchestrates. The tooling executes.

Call real tools (gh, sf, validated APIs), not "Claude, write the API call"

Same inputs, same result: testable and auditable

Security

Skills are scanned before they land

  • Every plugin PR runs Cisco skill-scanner + Snyk agent-scan
  • Both target OWASP Agentic Skills Top 10
  • Branch protection: merge blocked until both pass + 1 review
  • Bypasses are admin-only and logged
  • Accepted risks render as warnings on the catalog page
  • cold open: Instagram AI support, account takeover via prompt injection, no creds (thecybersecguru.com)
  • closer to home: jqwik supply-chain injection, hidden with ANSI escapes; Claude flagged it (arstechnica, 2026/05)
  • a skill is instructions an agent reads, so scan before install
  • two scanners, different DBs, redundant on purpose
  • OWASP Agentic Top 10; no self-merge; bypass logged
  • lethal trifecta: injection + network + filesystem
  • [ASK] Who would you trust to write the skills you install? This gate is the answer.
  • accepted findings show on the install page
